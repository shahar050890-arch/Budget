# 💰 התקציב שלי — ניהול תקציב בצ'אט

אפליקציית ניהול תקציב אישי בעברית, שמתנהלת כולה דרך שיחה.
כותבים בשפה חופשית כל מה שקורה עם הכסף — והאפליקציה בונה בעצמה את התמונה
המלאה: הוצאות, הכנסות, כרטיסי אשראי, חובות, הגבלות חודשיות, הפרשות לחיסכון
ולמניות, ותוכניות חיסכון ליעדים.

**בלי התקנה, בלי שרת, בלי חשבון.** הכול רץ בדפדפן והנתונים נשמרים אצלכם במכשיר.

## הפעלה

פותחים את `index.html` בדפדפן. זהו.

```bash
# או, אם מעדיפים שרת מקומי:
python3 -m http.server 8000
# ואז לגלוש אל http://localhost:8000
```

## איך מדברים עם האפליקציה

הכול נכתב בשורת הצ'אט בשפה חופשית. דוגמאות:

### הכנסות
| מה כותבים | מה קורה |
|---|---|
| `המשכורת שלי 12000` | נקבעת המשכורת החודשית |
| `אני מרוויח 15,500 ב-10 לחודש` | משכורת + יום קבלה |
| `קיבלתי בונוס 3000` | הכנסה חד־פעמית |

### הוצאות
| מה כותבים | מה קורה |
|---|---|
| `קניתי קפה 28` | הוצאה בקטגוריית מסעדות |
| `שילמתי 350 בסופר בויזה` | הוצאה בקטגוריית מזון, נזקפת לכרטיס ויזה |
| `אתמול דלק 300` | הוצאה בתאריך אתמול, קטגוריית תחבורה |
| `5k על ביטוח` | 5,000 ₪ בקטגוריית ביטוח |

הקטגוריה מזוהה אוטומטית מתוך המילים (16 קטגוריות, מאות מילות מפתח).

### כרטיסי אשראי
| מה כותבים | מה קורה |
|---|---|
| `כרטיס ויזה מסגרת 10000 חיוב ב-10` | כרטיס עם מסגרת ויום חיוב |
| `כרטיס מאסטרקארד מסגרת 5000` | כרטיס נוסף |

כל חיוב שנרשם על כרטיס מנוכה מהמסגרת, עם התראה בניצול של 75% ומעלה.

### חובות והלוואות
| מה כותבים | מה קורה |
|---|---|
| `יש לי הלוואה 20000 החזר 800 בחודש` | חוב + החזר חודשי + חישוב מתי ייסגר |
| `הלוואה 30000 בריבית 8% החזר 900` | הריבית משמשת לייעוץ חוב־מול־חיסכון |
| `שילמתי 800 על ההלוואה` | היתרה קטנה בהתאם |

### כמה כסף יש לי עכשיו
| מה כותבים | מה קורה |
|---|---|
| `יש לי בעובר ושב 8000` | יתרת העו"ש |
| `יש לי בחיסכון 20000` | יתרת החיסכון |
| `יש לי במניות 15000` | שווי תיק המניות |
| `כמה ההון שלי?` | נכסים פחות חובות וחיובי אשראי צפויים |

היתרות מתעדכנות לבד: הוצאה במזומן יורדת מהעו"ש, הפקדה ליעד עוברת מהעו"ש
לחיסכון, וחיוב אשראי לא יורד מיד אלא נספר כ"חיוב צפוי" עד יום החיוב.
תמיד אפשר לתקן ידנית — פשוט כתבו את הסכום הנכון.

### להתייעץ
| מה כותבים | מה קורה |
|---|---|
| `אני יכול לקנות טלוויזיה ב-3000?` | **כן / לא / כן אבל בקושי** — עם הנימוק |
| `מה אתה ממליץ?` | אבחון מלא עם ציון 0–100 והצעד המשתלם ביותר |
| `איך אני עומד?` | אותו אבחון |
| `עדיף להחזיר את החוב או לחסוך?` | תשובה לפי הריבית בפועל |
| `איפה אני מבזבז הכי הרבה?` | הקטגוריה הגדולה וכמה קיצוץ יחסוך בשנה |

תשובת "כן/לא" נשענת על שלושה דברים: כמה זמין בעו"ש אחרי חיובי אשראי צפויים,
מה זה עושה לתקציב החודשי, וכמה חודשי הפרשה ליעד הסכום הזה שווה.

### הגבלות והפרשות
| מה כותבים | מה קורה |
|---|---|
| `הגבלה למסעדות 800` | תקרה חודשית לקטגוריה, עם התראות |
| `להפריש 1000 לחיסכון` | הפרשה חודשית קבועה |
| `10 אחוז למניות` | הפרשה כאחוז מההכנסה |

### יעדי חיסכון
| מה כותבים | מה קורה |
|---|---|
| `אני רוצה לחסוך לרכב שעולה 15000 היעד ארבעה חודשים` | נבנית תוכנית: 3,750 ₪ בחודש, אבני דרך, ובדיקה אם זה בכלל אפשרי לפי המצב |
| `לחסוך לטיול ליפן 20000 ב-8 חודשים` | יעד נוסף |
| `הפקדתי 3750 לרכב` | ההפקדה נרשמת ומתעדכנת ההתקדמות |

אם היעד לא ריאלי לפי הכסף הפנוי, האפליקציה אומרת את זה ומציעה חלופות —
להאריך את התקופה, להקטין את היעד, או לקצץ בהוצאות.

### שאלות ופקודות
`מה המצב?` · `כמה הוצאתי על מזון?` · `כמה יש לי בעובר ושב?` · `בטל` · `עזרה`

## מה יש במסכים

- **צ'אט** — הממשק הראשי. כל פעולה מקבלת תשובה עם ההשלכות שלה על התקציב.
- **מצב כספי** — כמה פנוי החודש, קצב יומי מומלץ, היתרות וההון הנקי, פילוח הוצאות, מצב ההגבלות ותוכנית חודשית מלאה.
- **עסקאות** — כל התנועות לפי ימים, עם אפשרות מחיקה.
- **אשראי וחובות** — ניצול מסגרות וסטטוס כל חוב.
- **חיסכון והשקעות** — התקדמות בכל יעד וההפרשות הקבועות.

## איך מחושב "פנוי החודש"

```
פנוי = הכנסות
     − הוצאות שנרשמו בפועל
     − החזרי חובות שטרם שולמו החודש
     − הפרשה לחיסכון
     − הפרשה למניות
     − הפרשות ליעדים שטרם הופקדו החודש
```

הפקדה ליעד או תשלום חוב שכבר בוצעו נספרים כתנועה בפועל בלבד ומנוכים
מההתחייבות הפתוחה — כך שאותו כסף לעולם לא נספר פעמיים.

## איך מחושב "ההון הנקי"

```
הון נקי = עובר ושב + חיסכון + מניות
        − חובות והלוואות
        − חיובי אשראי שנרשמו וטרם ירדו
```

כרית הביטחון נמדדת מול קצב השריפה החודשי. כל עוד לא נצברו נתונים של
חודשיים מלאים, הקצב מוערך כ-70% מההכנסה במקום להסתמך על חודש חלקי — אחרת
כרית של חודש נראית כמו כרית של שנה.

## נתונים ופרטיות

הכול נשמר ב-`localStorage` של הדפדפן. שום מידע לא נשלח לשום מקום.
בסרגל העליון יש כפתורי גיבוי (⬇︎) ושחזור (⬆︎) לקובץ JSON, וכפתור איפוס (⟲).

## מבנה הקוד

```
index.html          מבנה המסכים
assets/styles.css   עיצוב, RTL, מצב כהה/בהיר אוטומטי
src/util.js         פורמט מטבע, תאריכים, עזרי DOM
src/store.js        המצב, שמירה מקומית וכל החישובים הפיננסיים
src/parser.js       הבנת עברית חופשית → פעולה מובנית
src/engine.js       ביצוע הפעולה וניסוח התשובה
src/render.js       ציור המסכים
src/app.js          חיבור הצ'אט, הטאבים והפעולות
tests/logic.test.js בדיקות לניתוח השפה ולחישובים
```

ללא תלויות, ללא שלב בנייה.

## בדיקות

```bash
node tests/logic.test.js
```

70 בדיקות המכסות את ניתוח השפה, החישובים הפיננסיים, עדכון היתרות,
תשובות הכן/לא, ומניעת ספירה כפולה.
